우드득 (WOODUDUK) — 멀티플레이 네트워크 게임
팀 프로젝트 · 개발 5인 QA 1인
담당: 데이터 · 네트워크
🎬 플레이 영상 ⌨ 기술문서 💻 GitHub
Firebase RTDB 기반의 실시간 멀티플레이 게임. 매칭·동기화·사망 정산·디버그 툴 등 데이터 및 네트워크 파트를 담당.
주요 구현
  • Firebase RTDB 매칭 시스템 — 단일 필드 쿼리 한계를 stateAndTier 복합키(예: "waiting_3")로 우회. 티어별 방 탐색 쿼리 구현
  • 실시간 플레이어 상태 동기화 — RoomLiveSync: 0.33초 간격 Firebase 갱신·구독. 고스트(AI) 플레이어 사망 처리 포함
  • 비동기 사망/순위 정산 — ServerValue.Timestamp 기반 사망 시각 기록 → 전원 사망 감지 시 시간 역순 정렬로 순위 자동 산정. 호스트 없이 누구든 기록 가능한 구조, _gameEnded 가드로 중복 방지
  • Unity Editor 디버그 툴 — partial class 12개 파일 구성. 매칭·런종료·Firebase 탐색·밸런스 시뮬 등 탭 구성. 코나미 코드로 비밀 탭 해금 기능 포함
  • 네트워크 구조 전환 설계 경험 — FishNet + EdgeGap 기반 서버 멀티플레이를 실구현하여 동작시킨 후, 기획 전환으로 새 프로젝트(우드득)에 Firebase RTDB 서버리스 구조를 처음부터 설계·구현. 서버 기반과 서버리스 두 방식의 트레이드오프를 직접 경험

Rune Bound Prototype — 뱀서라이크 게임
팀 프로젝트 · 개발 4인 QA 1인
담당: 몬스터 · 보스 · 스테이지 · 스폰
🎬 플레이 영상 ⌨ 기술문서 💻 GitHub
대량의 몬스터와 다단계 보스 전투를 중심으로 한 뱀서라이크 프로토타입. 몬스터 AI, 보스 패턴 시스템, 스테이지 구성, 스폰 시스템 전 파트를 설계·구현.
일반 몬스터 AI
  • State Machine (FSM) — IMonsterState 인터페이스 기반 5개 상태(Idle/Chase/Attack/Hit/Dead). MonsterBrain이 Sensor → 전환 판단 → StateChanger 흐름으로 매 프레임 처리
  • Strategy Pattern (공격 전략) — IAttackStrategy 인터페이스로 근접·원거리·돌진·자폭·소환마법사 5종 분리. MonsterStrategyFactory가 Init 시점에 MonsterData.attackType으로 전략 주입
  • Template Method (MonsterBase) — 스탯 스케일링, 사망, 아이템 드롭 공통 흐름 고정. NormalMonster / BossBase가 구체 동작만 오버라이드
보스 패턴 시스템
  • Phase 기반 전환 — PhaseController가 HP 비율을 매 프레임 감시 → 임계값 도달 시 BossBrain.OnPhaseChanged() 호출. 현재 패턴 수행 중이면 예약 후 완료 시 전환
  • PatternExecutor — 우선순위 패턴 우선 탐색 후 일반 라운드로빈. preDelay(선딜레이) 지원. 패턴 못 찾으면 0.5초 대기 후 재탐색
  • 6가지 보스 패턴 — Meteor / Pickup / Slam / Summon / Throw / Trap. 각각 BossPattern(CanUse/CreateState) + IBossState(Enter/Update/Exit) 구조
  • ScriptableObject 데이터 드라이븐 — BossData에 PhaseData 목록 → 각 페이즈별 PatternSet 지정. 코드 수정 없이 에디터에서 패턴 구성 변경 가능
스테이지 & 스폰
  • StageManager — 실시간 난이도 성장(_globalScale), 웨이브 자동 전환, 보스 페이즈 중 성장 중지·캐싱, 스테이지 간 보너스 배율 적용
  • SpawnManager — 가중치 기반 랜덤 몬스터 선택. SINGLE/CIRCLE/BURST 3가지 스폰 패턴. SPAWNRUSH·SPAWNEPIC·SPAWNBOSS 이벤트 타입. 지면 Raycast 보정 + LeanPool 오브젝트 풀링

포탈 퍼즐 게임 (Portal 모작) — 개인 프로젝트
개인 프로젝트 · 1인 개발
전 파트 단독 구현
🎬 플레이 영상 ⌨ 기술문서
Valve Portal 시리즈의 핵심 메커닉을 Unity에서 직접 구현한 1인칭 퍼즐 프로토타입. 포탈 물리·배치 로직부터 환경 퍼즐·사운드까지 전 파트를 단독 개발.
주요 구현
  • 포탈 텔레포트 물리 수식 — 입구 포탈 로컬 공간 기준으로 위치·회전·속도 세 가지를 변환 후 출구 포탈 월드 공간으로 역변환. 운동량(속도) 보존으로 관성 유지
  • 포탈 배치 로직 — 벽 경계 클램핑(가장자리 삐져나옴 방지), 벽 두께 검증, OverlapBox 겹침 차단 3단계 검증
  • 충돌 처리 & 루프 방지 — _isTeleport 플래그로 0.2초 재진입 차단. ReadyToPortal로 통과 직전 충돌 레이어 무시 처리
  • 오브젝트 잡기 — Rigidbody.MovePosition + Vector3.Lerp으로 부드럽게 끌어당기는 Grab 시스템. 중력·회전 제어 포함
  • 환경 인터랙션 — 압력 버튼(PushButton: 스쿼시 애니메이션), 엘리베이터 시퀀스(문 열기→플레이어 이동→목적지 이동 코루틴), 큐브 디스펜서
⚠ 미구현 사항 (기술적 한계 · 시간 제약)
  • Render Texture 카메라 미적용 — 포탈 내부에 상대 포탈 시야가 렌더링되지 않음 (RenderTexture + 카메라 위치 동기화 방식 학습 필요)
  • 포탈 통과 연출 미구현 — Stencil Buffer + Oblique Near-Clip Projection을 활용한 반신 통과 화면 처리 부재
